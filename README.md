# 美团小袋 · 周末闲时助手 🦘

**一句话描述**：一个 Agent 完成规划、省钱、协同、执行全链路——只有美团同时拥有商户、券、团购、骑手四张网，这才能闭环。

## 这是什么

美团小袋是一个基于 LLM Function Calling 的周末活动规划 Agent Demo。用户用自然语言描述出行需求，Agent 自动解析意图、推荐活动与餐厅、匹配优惠券、检测闪送场景，最终生成可执行的完整行程方案。

**核心理念**：不是搜索推荐——是「帮你把事情做完」。

## 功能亮点

| 功能 | 说明 |
|------|------|
| 📋 **自然语言规划** | 一句话输入，AI 自动解析场景、人数、时间、偏好、预算 |
| 🧩 **美团拼场** | 飞盘、徒步、密室、剧本杀等组队找搭子，查看人数/难度/时间档 |
| 💰 **三层省钱引擎** | 已有券匹配 → 可领券检测 → 同品质比价，自动省到极致 |
| ⚡ **一键执行** | 购票、订座、取号、领券一次性确认，弹窗汇总所有操作 |
| 🛵 **场景化闪送** | 高温推冷饮、纪念日推鲜花、带娃推零食——自动识别场景 |
| 🌤️ **天气感知** | 实时天气影响活动推荐（下雨推室内、高温降户外优先级） |
| 👨‍👩‍👧 **多人设适配** | 家庭（带娃年龄+饮食约束）、朋友（男女比例）、情侣（默认2人） |
| 📤 **方案分享** | 一键生成格式化行程卡片，复制发送给朋友/家人确认 |
| ⏱️ **排队感知** | 餐厅排队/等位数据影响规划决策，提前取号提醒 |

## 技术栈

- **前端**：React 18 + TypeScript + Vite 8 + Tailwind CSS v4
- **AI**：DeepSeek API (`deepseek-chat`)，Function Calling 模式
- **架构**：Agent Loop 模式，LLM 做决策、工具保底限

## 快速开始

```bash
cd demo
npm install
npm run dev
```

打开 `http://localhost:5173`，在输入框或首页示例中选择一个场景开始。

## 设计理念

详细设计文档见 [DESIGN.md](../DESIGN.md)。

核心壁垒：**美团数据闭环 × 三层省钱引擎**

通用 LLM 能排行程但不能执行——它没有商户实时数据、没有用户券包、没有团购价格、没有即时配送网络。这四样只有美团同时具备。

Agent 在规划流程中嵌入三层省钱计算（已有券 → 可领券 → 同品质比价），每一步直接贡献平台 GMV：券核销率 ↑、团购转化率 ↑、闪送订单量 ↑。
