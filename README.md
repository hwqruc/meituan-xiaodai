# 美团小袋 · 周末闲时助手 🦘

**一句话**：一个 Agent 把"想想算了"变成"出门"——只有美团同时拥有商户、券、团购、骑手四张网，这才能闭环。

---

## 这不是搜索推荐，是决策引擎

用户周六在家刷手机。通用搜索告诉他密室在哪、火锅店有什么券——但他需要自己打开三个 App、对比价格、算时间、问朋友要不要去。大多数人刷到这里就算了。

**小袋做的是把"犹豫"变成"行动"**。一句话输入，Agent 在一个对话里完成规划、省钱、下单、配送的全链路。这不是存量的重新分配——这个消费原本不会发生。

---

## 商业引擎：三条增量路径

小袋不靠"帮用户省钱"来创造价值——靠的是创造原本不存在的消费决策。

### 1. 决策转化率：从"想想算了"到一整个下午的客单

每次"想想算了"的流失，美团损失的不是一张券，是活动+餐厅+闪送三笔订单。小袋把决策成本降到一句话——用户说"周末下午想出去"，几分钟后行程已排好、券已匹配、下单按钮在眼前。这次消费就锁定了。

```
原本：用户刷手机 → 想想算了 → 订单为零
现在：用户说一句话 → Agent 排行程 → 活动票 + 餐厅订座 + 闪送冰饮 → 一整个下午的客单
```

### 2. 交叉品类带动：一次规划，三个品类激活

用户买密室票，小袋顺带带动了餐厅订座和喜茶闪送。这不是推荐引擎的"猜你喜欢"，而是时间线编排的自然结果——"密室玩完刚好6点，旁边这家火锅不用排队，帮你订了"。三个品类一次激活，这是美团其他入口做不到的。

### 3. 券的主动消耗：把沉默补贴变成实际核销

用户券包里有大量过期未用的券。小袋在规划时主动匹配——这不叫让利，叫**帮商户把已经发出去的补贴变成实际核销**。核销率 ↑ → 商户愿意继续投放 → 券池更丰富 → 用户更省钱 → 转化更高。不是补贴战，是效率战。

```
不是：美团让利 → 用户省钱
而是：沉默补贴 → Agent 激活 → 商户核销 ↑ → 供给 ↑ → 飞轮转起来
```

## 社交引擎：拼场 × 协同，不是两个功能是一个网络

当前拼场是"solo 找搭子"，协同是"分享给朋友确认"——两个独立功能，没有网络效应。

更有力的设计：**让每一次规划成为一个可加入的"局"**。

### 约局机制

小袋生成的行程不只是个人计划，而是一个可加入的局。朋友打开分享链接，不只是"确认"，而是可以选择"我也要去"——自动变成拼场，人数扩大，订单扩大。

```
发起人规划"周六密室+火锅"
    │
    ├── 分享给朋友
    │       │
    │       ├── 朋友 A：确认 ✓
    │       ├── 朋友 B：我也要去！→ 自动加入 → 拼场人数 2→3
    │       └── 朋友 C：我带一个人 → 拼场人数 3→5，客单价 ↑
    │
    └── 结果：原本 2 人局变成 5 人局，密室票+火锅+闪送全部翻倍
```

### 三条网络效应

| 路径 | 说明 |
|------|------|
| **协同 → 拼场** | 分享确认变成加入，人数扩大，订单规模跟着涨 |
| **拼场 → 新用户入场** | 别人的局带你入场，第一次使用不是搜索而是被邀请 |
| **关系链沉淀** | 美团积累的不只是交易数据，是"谁和谁一起玩"的社交图谱——抖音知道你看了什么，美团可以知道你和谁出去玩、去了哪、花了多少 |

这条关系链是抖音没有的。内容平台知道你爱看什么视频，但不知道你周六和谁去密室、在哪吃的火锅、花了多少钱——这是更深一层的本地生活数据。

## 功能

### 两个入口，两种路径

| 入口 | 说明 |
|------|------|
| 📋 **我来规划** | 一句话描述需求，Agent 全自动规划：解析意图→推荐活动→匹配餐厅→组行程→省钱→分享 |
| 🧩 **加入一个局** | 浏览附近正在组队的拼场，一键加入——跳过规划，零决策成本出门 |

### 规划引擎

| 功能 | 说明 |
|------|------|
| 🌤️ 天气感知 | 下雨推室内、高温降户外优先级、36°C推冷饮闪送 |
| ⏱️ 排队感知 | 餐厅排队/等位影响决策，提前取号提醒 |
| 👨‍👩‍👧 多人设 | 家庭(带娃年龄+饮食)、朋友(男女比例)、情侣(默认2人) |
| 🧩 美团拼场 | 飞盘/徒步/密室/剧本杀等 8 类 10 场，加入已有组队 |
| 💰 三层省钱 | 已有券匹配 → 可领券检测 → 同品质比价 |
| 🛵 闪送推荐 | 高温→冷饮 / 约会→鲜花 / 带娃→零食，行程界面展示 |
| ⚡ 一键下单 | 购票·订座·取号·领券弹窗一次确认 |
| 🔄 换一换 | 行程每个活动/餐厅都支持替换替代方案 |

### 社交裂变

| 功能 | 说明 |
|------|------|
| 📤 **分享约局** | 生成"X人局"卡片，复制发给朋友 |
| 🙋 **我也去** | 朋友打开分享看到行程，点"我也去"自动加入，人数+1、省钱重算 |
| 🧩 **加入一个局** | 首页直接浏览可加入的局，不用自己规划就能出门 |

## 技术栈

React 18 · TypeScript · Vite 8 · Tailwind CSS v4 · DeepSeek API (`deepseek-chat`, Function Calling) · Agent Loop 架构

## 快速开始

```bash
cd demo
npm install
npm run dev        # → http://localhost:5173
npm run build      # 生产构建 → dist/
```
